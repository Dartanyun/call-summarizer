# Что нового

Все заметные изменения программы. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
номера версий — по [семантическому версионированию](https://semver.org/lang/ru/).

Новые изменения записывайте в раздел «Не выпущено»: при выпуске версии
(`python3 scripts/release.py bump …`) он станет разделом этой версии и текстом релиза на GitHub.

## [Не выпущено]

## [1.3.1] — 2026-10-20

### Добавлено

- Проверка обновлений раз в день и обновление в один клик: установщик Windows ставит новую версию
  сам, без прав администратора; пакет .deb — через системный запрос пароля; архив .tar.gz — без
  пароля. Окно «Что нового», «Пропустить эту версию», раздел «Обновления» в настройках.
- Программа замечает две свои копии на компьютере — например, пакет .deb и старую установку из
  install.sh, ярлык которой перекрывает пакет в меню, — и предлагает оставить новую.
- В настройках видно, как установлена программа: пакет .deb, установщик Windows, домашняя папка…

### Исправлено

- Подсветка пунктов в настройках, справке и окне задач наезжала на соседние пункты.
- Кнопки «Спросить» и «Итоги недели» оставались подсвеченными после выбора созвона с клавиатуры.
- В узком окне обрезались кнопки на экране записи, приветствие и таблица статистики.
- Лишние пробелы перед ссылками в ответах и итогах недели; слишком яркая черта между вопросами.
- Начала глав на шкале плеера были почти не видны.
- install.sh предупреждает, если в системе уже стоит пакет .deb.

## [1.3.0] — 2026-10-20

### Добавлено

- Шаблоны саммари под тип встречи: планёрка, 1:1, собеседование, звонок с клиентом, лекция,
  свой шаблон; по умолчанию тип определяется автоматически. У созвона шаблон меняется в «⋯».
- Хронология: главы созвона с таймкодами — в саммари и чёрточками на шкале плеера.
- Отметки «важный момент» во время записи и прослушивания: Ctrl+B, Meta+Shift+B / Win+Shift+B
  из любого окна, кнопка на экране записи и пункт в трее. В саммари — раздел «Отмеченные моменты»,
  на шкале — флажки, их можно подписать или удалить.
- Вкладка «Статистика»: доля времени участников (диаграмма), темп речи, реплики, перебивания,
  самый длинный монолог, слова-паразиты, частые слова.
- «Спросить у созвонов» (Ctrl+K): вопросы по всем записям или по одной, ответ со ссылками
  на моменты; уточняющие вопросы в том же разговоре.
- «Итоги недели»: главное, решения, задачи по людям, что зависло — по кнопке или по расписанию.
- Локальная модель через Ollama для саммари, вопросов и итогов недели — текст не уходит в интернет.
- Календарь по ссылке iCal: название встречи и участники из приглашения, повторяющиеся встречи.
- Задачи в YouTrack и Todoist, напоминания в календарь (.ics), копирование списком.
- Экспорт в PDF и Word, сообщение для Telegram, заметки Obsidian (с участниками-ссылками,
  можно сохранять каждое саммари автоматически).
- Шумоподавление перед распознаванием и распознавание на видеокарте NVIDIA (CUDA) с переходом
  на процессор, если видеокарты нет.
- Встроенная справка (F1): 14 разделов, поиск, кнопка «Проверить программу».

### Изменено

- Настройки разбиты на разделы: Общие, Саммари, Распознавание, Запись, Тихий режим, Интеграции,
  Хранение; у интеграций есть кнопки «Проверить».

## [1.2.0] — 2026-10-20

### Добавлено

- Готовые сборки — Python и все библиотеки уже внутри, ничего докачивать не нужно. Для Windows —
  установщик (права администратора не нужны, удаление через «Параметры → Приложения») и архив без
  установки, для Linux — пакет `.deb` для Debian 12+ и Ubuntu 22.04+ и архив `.tar.gz` с `install.sh`
  для других дистрибутивов. Сборки прикладываются к каждому релизу; перед этим GitHub Actions
  ставит каждую, проверяет пробным распознаванием и удаляет.
- Самопроверка `call-summarizer --self-check`: на месте ли ffmpeg, Qt, распознавание речи и
  говорящих (`--full` — с пробным распознаванием).

### Изменено

- `install.sh` умеет ставить готовую сборку из архива — без Python и без скачивания библиотек.
- Горячая клавиша Meta+Shift+Z в KDE включается и при первом запуске программы — например, если
  она поставлена из пакета `.deb`.

## [1.1.0] — 2026-10-20

### Добавлено

- Версия для Windows 10/11, которая ставится и работает под обычным пользователем, без прав
  администратора: `install.cmd` сам скачивает Python 3.12 и библиотеки в папку пользователя,
  создаёт ярлык в меню «Пуск». Удаление — `uninstall.cmd`.
- Запись в Windows через WASAPI: микрофон и всё, что звучит в колонках/наушниках, на отдельных дорожках.
- Определение звонков в Windows по отметке «микрофон используется» (Telegram, Discord, Zoom, браузеры…).
- Автозапуск и горячая клавиша в Windows: Win+Shift+Z, а если она занята — Ctrl+Alt+Z.
- Viber в списке программ для звонков.
- Номер версии внизу окна настроек и команда `call-summarizer --version`.
- Проверки в GitHub Actions: код и версия при каждом коммите, установка и работа на чистой Windows,
  автоматический релиз по метке версии.

### Исправлено

- Временные файлы при определении говорящих закрываются до переименования (в Windows иначе ошибка).

## [1.0.0] — 2026-10-20

Первая версия, для Linux (Debian, KDE, GNOME и др.).

### Добавлено

- Запись созвона на две дорожки — микрофон и звук собеседников, пауза, импорт готовых записей.
- Локальное распознавание речи через faster-whisper (large-v3-turbo) и словарь терминов.
- Определение говорящих через sherpa-onnx, переименование участников и запоминание голосов.
- Саммари через Claude: итоги, решения, задачи и имена участников из разговора.
- Плеер с таймкодами, временная шкала реплик и поиск по транскриптам.
- Тихий режим: значок в трее с состоянием (ожидание, запись, расшифровка), автозапуск,
  предложение записать звонок в Telegram, Discord, Zoom и браузере, горячая клавиша Meta+Shift+Z.
- Необязательная автоочистка старых аудиозаписей.
- Светлая и тёмная тема, иконка приложения.
