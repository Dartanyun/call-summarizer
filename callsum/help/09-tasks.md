# Задачи и трекеры

Задачи из саммари — раздел «Задачи» в формате «Кто — что — срок». Кнопка **«Задачи»**
(значок списка вверху справа) открывает их списком: отметьте нужные и выберите, куда отправить.

| Куда | Что получится |
|---|---|
| **YouTrack** | задачи в выбранном проекте; в описании — исполнитель, срок, созвон и момент записи |
| **Todoist** | задачи во «Входящих» со сроками |
| **Напоминания…** | файл `.ics`: событие в день срока в 10:00 с напоминанием за 15 минут; откройте его в календаре |
| **Скопировать** | список задач текстом |

## Настройка

«Настройки» → «Интеграции»:

- **YouTrack**: адрес (например `https://company.youtrack.cloud`), постоянный токен
  (профиль → «Безопасность аккаунта» / Account Security → «Новый токен», доступ — YouTrack)
  и короткое имя проекта (например `APP`).
- **Todoist**: токен API — настройки Todoist → «Интеграции» → «Разработчик» → «Токен API».

Токены хранятся в файле настроек на этом компьютере. Задачи отправляются, только когда вы
нажимаете кнопку.
