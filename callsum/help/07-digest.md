# Итоги недели

Кнопка **«Итоги недели»** в левой колонке. По саммари всех созвонов за неделю модель
собирает:

- **главное** за неделю;
- **решения** — со ссылками на созвоны;
- **задачи по людям** — кто что должен и к какому сроку;
- **что зависло** — вопросы, которые обсуждали несколько раз без решения, задачи без срока;
- **список созвонов** недели.

Стрелки ‹ › переключают недели. Если после сборки появились новые созвоны, программа
предложит **«Обновить»**.

## По расписанию

«Настройки» → «Саммари» → «Итоги недели»:

- **По пятницам в 17:00** (по умолчанию) — итоги текущей недели;
- **По понедельникам в 10:00** — итоги прошлой недели;
- **Не собирать сами** — только по кнопке.

Итоги собираются, только если программа запущена (можно в трее) и на неделе были созвоны
с саммари. Когда они готовы, придёт уведомление. Итоги хранятся в папке `digests` рядом
с записями.
