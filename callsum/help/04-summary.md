# Саммари и шаблоны

## Кто пишет саммари

«Настройки» → «Саммари» → «Модель»:

- **Claude API** — лучшее качество. Нужен ключ с [console.anthropic.com](https://console.anthropic.com/settings/keys);
  оплата — по тарифам Anthropic. В облако уходит только текст транскрипта, не звук.
- **Локальная модель (Ollama)** — текст не покидает компьютер, бесплатно, но качество и скорость
  зависят от модели и компьютера. Как настроить:
  1. Установите Ollama: [ollama.com/download](https://ollama.com/download).
  2. Скачайте модель, например `ollama pull qwen2.5:14b` (нужно ~16 ГБ памяти) или
     `ollama pull qwen2.5:7b` для слабых компьютеров.
  3. В настройках выберите «Локальная модель» и модель из списка (кнопка «Обновить» — если
     список пустой).

Та же модель отвечает на [вопросы по созвонам](help:06-ask) и собирает [итоги недели](help:07-digest).

## Шаблоны

Структура саммари зависит от типа встречи:

| Шаблон | Разделы |
|---|---|
| Общий | Кратко, ключевые темы, решения, задачи, открытые вопросы |
| Планёрка | по участникам: сделано / в работе / мешает, блокеры, решения, задачи |
| Встреча 1:1 | как дела, обратная связь, развитие и цели, договорённости |
| Собеседование | опыт, вопросы и ответы, сильные стороны, сомнения, условия |
| Звонок с клиентом | задача клиента, требования, возражения, договорённости, следующий контакт |
| Лекция или обучение | основные идеи, примеры, вопросы из зала |
| Свой шаблон | ваш текст в «Настройках» → «Саммари» |

По умолчанию шаблон **определяется автоматически** — модель сама понимает, что это за встреча.
Для одного созвона шаблон можно сменить: **«⋯» → «Сделать саммари заново» → шаблон**.

Во всех шаблонах есть **задачи** чек-листом «Кто — что — срок» (сроки вроде «к пятнице»
переводятся в даты) и **хронология** — главы созвона с таймкодами. Главы видны на шкале
плеера, задачи можно отправить в [трекер](help:09-tasks).

## Глубина анализа и модель Claude

- Opus — лучшее качество, Sonnet — быстрее и дешевле, Haiku — самый дешёвый.
- «Глубина анализа» — сколько модель думает перед ответом: дольше — точнее.

## Если саммари не получилось

- «Не задан API-ключ» / «ключ не подошёл» — проверьте ключ в настройках.
- «Не удалось подключиться к Ollama» — запущен ли Ollama (`ollama serve` или значок в трее).
- «В Ollama нет модели» — скачайте её командой из сообщения.
- Можно повторить: **«⋯» → «Сделать саммари заново»**.
