# Обновления

Программа раз в день проверяет, не вышла ли новая версия. Если вышла — придёт уведомление,
а внизу слева появится ссылка **«⬆ Версия X»**. В окне обновления видно, что нового, и есть
кнопка **«Обновить»**.

| Как установлена программа | Как обновится |
|---|---|
| установщик Windows | скачает новый установщик и поставит его без прав администратора, программа перезапустится |
| пакет .deb | скачает пакет и поставит его — система спросит пароль |
| архив .tar.gz или install.sh | обновится в домашней папке сама, без пароля |
| без установки (.zip), из исходников | только сообщит о новой версии и откроет страницу релиза |

Пока идёт запись или обработка, обновиться нельзя — кнопка станет доступна, когда они закончатся.
Записи, настройки и запомненные голоса при обновлении сохраняются.

Проверка и настройки — «Настройки» → «Общие» → «Обновления»: там же кнопка **«Проверить сейчас»**
и галочка, чтобы выключить ежедневную проверку. «Пропустить эту версию» в окне обновления —
о ней больше не напомнит.

## Если репозиторий закрыт

Новые версии берутся со страницы релизов на GitHub; пока репозиторий открыт, ничего настраивать
не нужно. Если его закроют, GitHub будет показывать релизы только с токеном. Создайте
[токен с ограниченным доступом](https://github.com/settings/personal-access-tokens/new):
**Repository access** — только репозиторий call-summarizer, **Permissions → Contents** —
Read-only — и вставьте его в «Настройки» → «Общие» → «Токен GitHub».

## Две копии программы

Если на компьютере оказались две копии — например, пакет .deb и старая установка из install.sh
в домашней папке, — программа заметит это при запуске и предложит оставить одну, новую.
Старая копия иначе перекрывает новую в меню приложений.
