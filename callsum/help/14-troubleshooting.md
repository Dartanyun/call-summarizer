# Решение проблем

## Проверить программу

Кнопка **«Проверить программу»** внизу этого окна запускает самопроверку: на месте ли
ffmpeg, Qt, распознавание речи и говорящих, сертификаты для HTTPS. То же из терминала:
`call-summarizer --self-check`.

## Частые вопросы

**Дорожка «Собеседники» пустая.** Звонок шёл не через устройство вывода по умолчанию.
Выберите устройство в «Настройках» → «Запись» или оставьте «по умолчанию» — программа
сама переключается туда, где звучит звонок.

**Звонок не замечается автоматически.** Проверьте, что включена «Автозапись звонков» и что
название программы есть в списке «Приложения для звонков». В Windows звонок замечается,
когда программа берёт микрофон.

**Горячая клавиша не работает.** В KDE проверьте сочетание в Параметрах системы →
Комбинации клавиш. В Windows статус — в «Настройках» → «Тихий режим».

**Распознавание очень медленное.** Выберите модель поменьше («medium» или «small») или
включите видеокарту NVIDIA ([подробнее](help:03-recognition)).

**Много ошибок в словах.** Добавьте термины и имена в словарь, включите шумоподавление.

**Саммари не делается.** См. раздел «Если саммари не получилось» в [Саммари](help:04-summary).

**«Нет соединения с API Anthropic».** Если Claude API недоступен из вашей сети, укажите прокси
в «Настройках» → «Общие» → «Сеть» (например, тот, что даёт VPN-клиент: `http://127.0.0.1:10809`
или `socks5://127.0.0.1:10808`) и нажмите «Проверить». Логин и пароль — в адресе:
`http://логин:пароль@адрес:порт`. Через прокси пойдут все запросы программы в интернет.

**Проверить запись до созвона.** «Настройки» → «Запись» → «Проверить запись»: программа запишет
3 секунды с выбранных устройств (ничего не сохраняя) и скажет, пишется ли звук на каждой дорожке,
а если нет — почему. Скажите что-нибудь и включите звук, чтобы проверить обе.

**Windows: «Запись прервалась».** Текст ошибки подскажет причину. Частые: доступ к микрофону
закрыт в «Параметрах» → «Конфиденциальность и защита» → «Микрофон»; зависла служба «Windows Audio» —
перезапустите её или компьютер. Какие форматы пробовала программа, видно в журнале `app.log`.

**Windows: «отказала программе в записи звука» (invalid argument).** Windows отвергла даже
собственный формат устройства, открытый тем же способом, что и в OBS, — так бывает, когда запись
блокирует антивирус. Что OBS при этом пишет, не противоречит: антивирус решает отдельно для каждой
программы, и известным подписанным программам доверяет. В Kaspersky:
«Безопасность» → «Предотвращение вторжений» → «Управлять приложениями» → «Саммари созвонов» →
вкладка «Права» → «Изменение операционной системы» → «Подозрительные изменения в операционной
системе» → «Доступ к устройствам записи звука» → «Разрешить» → «Сохранить». В «Настройках
приватности» → «Контроль камеры и микрофона» не должно быть «Запретить всем приложениям
подключаться к микрофону». В другом антивирусе разрешите программе запись звука или добавьте её
в доверенные. Потом нажмите «Проверить запись».

**Windows: «Система Windows защитила ваш компьютер».** Сборка не подписана сертификатом:
«Подробнее» → «Выполнить в любом случае».

## Журнал

Сборка для Windows пишет журнал в `%LOCALAPPDATA%\CallSummarizer\app.log`, в Linux вывод
виден при запуске `call-summarizer` из терминала. Журнал автозаписи звонков — `callwatch.log`
в папке данных.
