# Горячие клавиши

## В окне программы

| Клавиши | Действие |
|---|---|
| Ctrl+R | начать / остановить запись |
| Ctrl+P | пауза записи |
| Ctrl+B | отметить важный момент (при записи или прослушивании) |
| Ctrl+O | открыть файл записи |
| Ctrl+F | поиск по созвонам |
| Ctrl+K | спросить у созвонов |
| Ctrl+Shift+C | скопировать саммари |
| Ctrl+, | настройки |
| F1 | справка |
| Delete | удалить созвон в корзину |

## Из любого окна

| Действие | Linux (KDE) | Windows |
|---|---|---|
| начать / остановить запись | Meta+Shift+Z | Win+Shift+Z или Ctrl+Alt+Z |
| отметить важный момент | Meta+Shift+B | Win+Shift+B или Ctrl+Alt+B |

В KDE сочетания можно сменить: Параметры системы → Комбинации клавиш → «Саммари созвонов».
В Windows, если оба варианта заняты другими программами, общесистемная клавиша не работает —
об этом написано в «Настройках» → «Тихий режим».
