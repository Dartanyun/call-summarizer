# Данные и приватность

## Что остаётся на компьютере

- **Звук** — всегда. Он никуда не отправляется.
- **Распознавание речи и определение говорящих** — локально.
- **«Отпечатки» голосов** — только в файле `voices.json`.

## Что и когда уходит в интернет

| Что | Куда | Когда |
|---|---|---|
| текст транскрипта | Claude API (Anthropic) | саммари, имена участников, вопросы, итоги недели — если выбран Claude |
| — | — | с локальной моделью (Ollama) текст не уходит никуда |
| запрос календаря | ваш календарь | раз в 15 минут, если подключён, только чтение |
| выбранные задачи | YouTrack, Todoist | только по кнопке |
| скачивание моделей | Hugging Face, GitHub | один раз, при первом использовании |
| проверка новой версии | GitHub | раз в день, если не выключено в настройках |
| скачивание обновления | GitHub | когда вы нажимаете «Обновить» |

## Где лежат файлы

| | Linux | Windows |
|---|---|---|
| записи, модели, итоги | `~/.local/share/call-summarizer` | `%LOCALAPPDATA%\CallSummarizer` |
| настройки и ключи | `~/.config/call-summarizer/config.json` | `%APPDATA%\CallSummarizer\config.json` |
| модели Whisper | `~/.cache/huggingface` | `%USERPROFILE%\.cache\huggingface` |

У каждого созвона своя папка в `calls`: дорожки звука, транскрипт, саммари. Открыть её —
«⋯» → «Открыть папку».

## Освободить место

«Настройки» → «Хранение» → «Удалять аудио старше…»: удаляется только звук, транскрипты
и саммари остаются. Чтобы сохранить звук конкретного созвона — «⋯» → «Не удалять аудио
при автоочистке».
